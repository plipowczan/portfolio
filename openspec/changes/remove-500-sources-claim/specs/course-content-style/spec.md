# Spec Delta

## ADDED Requirements

### Requirement: Course copy states no unmeasured scale limit

Copy that promotes or teaches the LLM Wiki method SHALL NOT state a number of sources, notes or documents up to which the method works without embeddings or RAG, nor a number at which it stops working, unless that figure is backed by a recorded measurement. This covers the landing at `/llm-wiki`, every lesson under `src/content/kurs/*.md`, and the generated `public/llms-full.txt` that repeats them. Describing what the method does (the agent reads the index and opens only the matching notes) and naming what to do when a base grows very large SHALL remain allowed, provided the text sets no threshold and gives no assurance of how far the method scales.

#### Scenario: Landing thesis states the mechanism, not a limit

- **WHEN** the "Index-first" thesis on `/llm-wiki` is read
- **THEN** it says the agent reads the index and opens only the matching notes
- **AND** it names no number of sources

#### Scenario: Lesson 1 sets no threshold

- **WHEN** lesson 1 (`/llm-wiki/kurs/1-zaloz-katalog`) is read
- **THEN** neither the progressive-disclosure section nor the FAQ names a number of sources up to which an index suffices
- **AND** the FAQ entry about a base that grows keeps a question and an answer, but the answer names no threshold and does not promise that the method keeps scaling

#### Scenario: Generated machine-readable copy follows the sources

- **WHEN** `public/llms-full.txt` is regenerated by `scripts/generate-llms-txt.js`
- **THEN** it contains no "500 źr" and the lesson 1 text in it matches the lesson file

#### Scenario: A search for the retired figure finds nothing

- **WHEN** `500 źr` is searched in `src/` and in `public/llms-full.txt`
- **THEN** there is no match that states a knowledge-base size limit
- **AND** the matches that remain, such as "~500 słów" describing the length of a note in a blog article, are unrelated to a size limit
