## 5. Technical concepts to cover (facts from brief — verify against brain via `brain-query` if expanding)

- **OKF** = markdown + frontmatter YAML, „authored by people, generated by agents". Knowledge Bundle = katalog `.md` (git clone = całość). Concept = 1 plik = 1 koncept. Pliki zarezerwowane: `index.md`, `log.md`. **Jedyne twardo wymagane pole: `type`.** Konsument MUSI tolerować nieznane klucze + broken links.
- **OKF vs LLM Wiki:** OKF = spec interoperacyjności („jak zapisać żeby było wymienialne"); LLM Wiki = metodologia („jak agent ma to budować/utrzymywać"). Komplementarne.
