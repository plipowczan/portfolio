# Vite Overview

## Core Principles
### 1. High Performance
Instant server start and lightning fast HMR (Hot Module Replacement) that stays fast regardless of app size.

### 2. Modern Defaults
Out-of-the-box support for TypeScript, JSX, CSS and more.

### 3. Build Optimizations
Pre-configured Rollup build with multi-page and library mode support.

## When to Use Vite
✅ Good for:
- Modern web applications (React, Vue, Svelte)
- SPAs requiring fast development cycle
- Static sites (with prerendering)

❌ Avoid for:
- Legacy browsers support (IE11 requires special plugins)
- Backend-heavy applications (unless using as frontend tool)
