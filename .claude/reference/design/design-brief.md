# Design Brief - Pawel Lipowczan Portfolio

## 1. Design Style & Aesthetic

- **Visual Style:** Modern, tech-forward, and professional.
- **Mood/Feeling:** Innovative, reliable, and expert.
- **Key Elements:**
  - **Color Scheme:** Distinctive green/teal gradients (`#00ff9d`, `#00b8ff`) against a dark navy/black background (`#0a0e1a`).
  - **Backgrounds:** Geometric network/mesh animations (Canvas API) and subtle gradients.
  - **Effects:** Glassmorphism (backdrop blur), smooth scroll animations, and hover effects with scale/glow.
  - **Typography:** Clean, modern sans-serif (Inter) for readability, with monospace (Fira Code) accents for code elements.

## 2. Target Audience

- **Primary:** Potential clients and employers looking for a software architect or technical advisor.
- **Secondary:** Tech recruiters, developers reading technical blog posts, and peers in the industry.
- **Preferences:** They value clarity, performance, modern aesthetics, and technical depth.
- **Devices:** Desktop (for detailed review) and Mobile (for quick access).

## 3. Key Features & Priorities

- **Core Features:**
  - **Hero Section:** Strong first impression with animated background and clear value proposition.
  - **Projects Showcase:** Visual grid of projects with technologies used.
  - **Blog:** Technical articles with good readability and code highlighting.
  - **Contact:** Easy-to-use contact form and social links.
- **Primary User Action:** Contacting Pawel or reading blog content.
- **Standout Elements:** The "Network Background" animation and the vibrant neon accents.

## 4. Design Context for AI

When generating code or design elements, keep in mind:

- **Responsiveness:** Mobile-first approach is crucial.
- **Performance:** Animations should be optimized (use `transform` and `opacity`).
- **Accessibility:** Ensure sufficient contrast for text, especially with the dark background.
- **Consistency:** Adhere strictly to the defined color palette and typography.
