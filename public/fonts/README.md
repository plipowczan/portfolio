# Self-hosted fonts

Generated by `npm run fonts:fetch` (`scripts/fetch-fonts.mjs`). Do not edit the
`.woff2` files or `src/styles/fonts.css` by hand — regenerate instead.

| File | Family | Subset |
| --- | --- | --- |
| `inter-latin.woff2` | Inter (variable, 300–700) | latin |
| `inter-latin-ext.woff2` | Inter (variable, 300–700) | latin-ext |
| `fira-code-latin.woff2` | Fira Code (variable, 400–600) | latin |
| `fira-code-latin-ext.woff2` | Fira Code (variable, 400–600) | latin-ext |

`latin-ext` is required, not optional: it carries ą ć ę ł ń ó ś ź ż. Dropping it
would silently fall back to a system font for most Polish text on the site.
